# AUVIC Website

Published via GitHub Pages from the `docs/` folder. Live at [www.auvic.ca](https://www.auvic.ca).

## File Structure

```
docs/                          ← GitHub Pages source root
├── index.html
├── about-us.html
├── competition-2025.html
├── competition-2026.html
├── contact-us.html
├── sponsors.html
├── vehicle-aerius.html
├── vehicle-kraken.html
├── vehicle-polaris.html
├── vehicle-redherring.html
├── vehicle-snappy.html
├── vehicle-trident.html
├── css/
│   └── styles.css
├── media/                     ← images, videos, 3D models
├── auvic-submarine-viewer/    ← standalone Three.js 3D viewer
│   ├── index.html
│   ├── main.js
│   └── models/
│       └── submarine.glb
└── CNAME                      ← custom domain: www.auvic.ca
```

## Local Development

```bash
npm install
npm run dev
```
